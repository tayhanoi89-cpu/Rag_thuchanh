# Retrieval Examples

Prompt 2 baseline results are generated by `scripts/baseline_retrieval.py`.

Queries to run and compare:

1. Exact keyword: `01/2014/TT-NHNN`
2. Semantic: `Quy định về việc vận chuyển tiền mặt trong ngân hàng là gì?`
3. Mixed: `Thông tư 01/2014/TT-NHNN quy định việc kiểm kê tiền mặt như thế nào?`

Dense uses `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`; document embeddings are cached only under `buoi_14/cache/`.

## Exact Keyword

Query: `01/2014/TT-NHNN`

- BM25 top 1: `169221__full` (score `2.438375`), the amendment document mentioning the exact code.
- Dense top 1: `168220__full` (score `0.387435`); `44209__full` was third (score `0.357387`).

Observation: BM25 is more sensitive to the exact document code, while dense ranking is semantic and does not guarantee exact-code priority.

## Semantic

Query: `Quy định về việc vận chuyển tiền mặt trong ngân hàng là gì?`

- BM25 top 1: `6e689cd0-6f81-11f1-94d6-fd5d6d5ff793__full` (score `4.893682`); `44209__full` was second (score `3.148700`).
- Dense top 1: `117310__full` (score `0.517029`); `44209__full` was third (score `0.445140`).

Observation: the two methods produce different rankings on a semantic query, which is the reason to compare them before building Hybrid Search.

## Mixed

Query: `Thông tư 01/2014/TT-NHNN quy định việc kiểm kê tiền mặt như thế nào?`

- BM25 top 1: `44209__full` (score `5.510567`).
- Dense top 1: `117310__full` (score `0.492070`); `44209__full` was second (score `0.431296`).

Observation: the exact code lets BM25 identify the relevant source first; dense retrieval still finds the source but ranks it lower.

## Hybrid RRF

Hybrid uses BM25 and Dense candidates from the same normalized corpus and combines ranks with `RRF = sum(1 / (60 + rank))`. Raw BM25 and cosine scores are not added.

Run:

```powershell
& ".venv\Scripts\python.exe" scripts\hybrid_search.py --query "01/2014/TT-NHNN" --candidate-k 20 --top-k 5
```

The same command can be run for the semantic and mixed queries above. The terminal output includes `bm25_rank`, `dense_rank`, `rrf_score`, and citation for every candidate.

Observed Hybrid top results with `candidate_k=20`, `top_k=5`:

- Exact keyword: `168220__full`, `169221__full`, `44209__full`.
- Semantic: `117310__full`, `25692__full`, `44209__full`.
- Mixed: `44209__full`, `168220__full`, `117310__full`.

Hybrid keeps candidates found by either retriever. These are ranking observations, not quality claims; evaluation is deferred to Prompt 5.

## Reranking

The reranker receives only Hybrid candidates (`candidate_k`), never the full corpus. It attempts the multilingual Cross-Encoder `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1`; if unavailable, the terminal explicitly reports `FALLBACK_LEXICAL`.

Run:

```powershell
& ".venv\Scripts\python.exe" scripts\rerank.py --query "01/2014/TT-NHNN" --candidate-k 20 --top-k 5
```

Observed with `NEURAL_CROSS_ENCODER`:

- Exact query: `44209__full` moved from Hybrid rank 3 to reranked rank 1.
- Semantic query: `44209__full` moved from Hybrid rank 3 to reranked rank 1.
- Mixed query: `44209__full` remained rank 1; `169221__full` moved from rank 4 to rank 2.

The reranker processed the Hybrid candidate set only (`candidate_k=20`), not the full corpus. No fallback was used in these runs.
